# OUA Fantasy Draft Scout

A read-only, self-contained player scouting dashboard with 2025–26 historical stats and partial 2026 preseason sample.

## Publish using GitHub Pages

1. Create a new public GitHub repository, e.g. `oua-draft-scout`.
2. Upload `index.html` and `.nojekyll` to the repository root.
3. Go to **Settings → Pages**.
4. Set **Source: Deploy from a branch**, **Branch: main**, **Folder: /(root)**, and save.
5. Open the URL shown in Pages settings and share it.

**Data warning:** this site embeds the scouting data into the HTML itself. Publishing it on GitHub Pages makes the underlying data publicly accessible. Publish only if comfortable with that.

The site is static and does not include authentication, live stats, or private fantasy-team management.
